This is the first post on the rebuilt site.

I'll use this space for writing about data science, forecasting, and whatever
problem has my attention. Posts are plain Markdown, so adding a new one is just
dropping a file in `content/posts/`.

## How to add a post

Create a file like `content/posts/my-post.md` with front matter at the top:

```yaml
---
title: "My Post Title"
date: 2026-11-15
draft: false
tags: ["forecasting"]
---
```

Then write in Markdown below it. Push to the branch, and the site rebuilds
and deploys on its own.
